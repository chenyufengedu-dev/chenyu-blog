# Cyber Office 体验改进方案（基于两轮外部评审 + 总设计师走查）

> **性质**：这是一份**改进路线图 / 方案**，不是逐行教程。按 P0→P1→P2 优先级列出"问题 → 改法 → 类型（美术/代码）→ 轨道"。
> 每个**代码任务**在真正开工时，我再单独写成"照着敲"的教程（保持你按 Task 记录的习惯）；**美术任务**你可与代码并行推进。
> 依据：两位外部评审意见 + 总设计师 UX 走查。取代之前"发言转身"素材方案。

---

## 一句话结论（评审共识）

当前是"完成度不错的**交互原型**"，最大短板不是缺动画，而是 **①画风不统一（一眼看出素材是拼的）②手机端会议核心失效 ③会议进程 / 编排逻辑没被传达**。这三点修好前，加动画不会提升质感。

## 已锁定的方向决策

| 决策 | 说明 |
|---|---|
| ❌ 放弃"发言转身面向用户" | 评审反对：毁圆桌构图、转身动画多轮后变成"被迫等待的加载动画"。角色保持坐姿朝桌心即可。 |
| ⏳ "镜头穿越到发言者"= 后期优化 | 这是理想效果，但实现难，暂缓。现在用"发言者高亮 + 头顶气泡 + 固定字幕 + 进度条"替代。 |
| 🎨 画风**向上统一**，不降级 | 统一到"精致像素插画"：重做桌子/背景，对齐角色的精度、透视（略俯视 3/4）、调色板。依然精美，只是"像一个人画的"。 |
| 🔁 默认缓存回放（已实现） | 实时会议留给愿意亲自试的访客，控成本。 |
| 🎞️ 美术 / 交互**双轨并行** | 你可同步做素材；代码任务我逐个出教程。 |

## 两条并行轨

- **美术轨（你主导，可即刻并行）**：P0-1 画风统一（重做桌子+背景）、P0-2 角色围坐素材、椅子、发言口型/眨眼多帧、猫。
- **交互轨（我出教程你敲）**：进度条、单一字幕、发言高亮、流程控制、手机响应式、编排可见开关等。

# P0 —— 不修则整体质感不成立

### P0-1　统一画风（当前最大廉价感来源）｜美术
- **问题**：背景（半写实、渐变、软阴影）+ 角色（软阴影像素）+ 桌子（矢量渐变金属柱）三套风格打架；且房间平视、桌子俯视，透视矛盾，桌子像贴纸。
- **改法**：
  - 定一套**统一透视：略俯视 3/4 角**，房间与桌子共用。
  - **重做桌子**：像素插画风、去金属渐变与软阴影，与角色同精度、同调色板。（当前最突兀，优先重做）
  - **重做/调整背景**：与角色同精度与透视；不必复杂，但风格一致。全站色板尽量收敛。
  - 位图缩放统一处理，避免浏览器把某些图糊边。
- **给 Chenyu 的出图要点**：一次把"桌子 + 背景"按同一段风格锚 + 同一 3/4 透视生成，别再单独出。

### P0-2　让圆桌真正"成立"｜美术 + 代码布局
- **问题**：五人贴墙一字排开、大小几乎一致（暴露"一排贴图"）、大白桌空占中心、猫成焦点。
- **改法**：
  - 角色真正围坐桌四周；**近大远小**（前排大、后排小）。前排¾背/侧对镜头**可接受**（更像真实会议），靠高亮+气泡+字幕指示发言者（见 P1-2/3）。
  - 桌上加**道具**（笔记本/纸/咖啡杯）填补空白、增生活感。
  - **猫移到角落**（窗台/桌沿/柜顶），不再占桌子正中。
- **素材**：角色按"座位固定朝向"出图（远侧正面、侧位¾正面、近侧¾背面），姿势 坐/举手/起身发言；**不需要"转身"帧**。

### P0-3　手机端可用（评审并列最严重）｜代码
- **问题**：场景固定 680px，390px 手机只见左半边、要横向拖，右侧角色发言时人不在屏内 —— 手机上"谁在发言"彻底失效。
- **改法**：场景做成**响应式"镜头"**：按容器宽度**整体等比缩放到完整可见**（`transform: scale()` + `ResizeObserver` 或容器查询），绝不让用户横向拖固定画布。（"发言时自动平移/放大到发言者"属 ⏳ 后期。）

# P1 —— 明显影响可用性

### P1-1　会议进程可见｜代码
- 加轻量**状态条**：`讨论中 · 3/5 · 当前：产品经理`；体现"讨论→质疑→总结"阶段；结束显示明确的**"会议完成"**。

### P1-2　单一字幕、绑定发言者｜代码
- 去掉"上方主持词 + 下方卡片"双字幕，**只留一处**（建议下方固定）。
- 字幕带发言者**名字（+可选头像/色点）**，改**像素风样式**（去圆角软阴影，用像素/等宽字体），让它像"这个人说的话"而不是"页面另一个模块"。

### P1-3　发言者高亮｜代码（+可选小美术）
- 非发言者**压暗 / 降饱和**，发言者全彩 + 头顶**像素气泡**。
- 拉开角色与背景的明度对比（现在米外套/白衬衫 vs 米白墙对比太低）。

### P1-4　流程控制与记录｜代码
- **常驻可折叠的发言记录（transcript）** + 进度；打字机效果支持**点击一次直接显示整段**；结论每条**可点回溯到出处**（谁、第几轮）。

### P1-5　修"假交互" + 入口清晰｜代码
- 拆成"**看演示**"与"**用我的议题开始会议**"两个层级清楚的入口；样本模式**锁定/隐藏议题输入**；按钮文案去掉 `DeepSeek` 黑话，改说用户能得到什么。

### P1-6　名牌不被挡 + 椅子/姿态统一｜美术 + 代码
- 名牌移到角色**下方**留白处（或做成桌前像素名牌），换像素字体；补齐**椅子**、统一默认坐姿（现有审稿人站着不一致）。

### P1-7　等待态 / 失败态｜代码（+小美术）
- 加"XXX 正在思考…"等待态、错误提示 + 重试入口（API 慢/报错时不再是僵住的静止画面）。

# P2 —— 打磨

- **空闲有生气**：呼吸 + 眨眼（否则静态图被当装饰）。
- **议题引导**：放 3 个可点示例议题。
- **打字机**：字间随机微延迟、标点停顿更久；支持点击跳过。
- **角色辨识度**：强化剪影与配色差异；名牌常驻。
- **动画定格化**：像素动画锁 **8–12fps 逐帧**，别用线性 CSS 补间（否则显廉价）。→ 对应你说的"多帧"：**多帧是对的，但要逐帧定格播，不是平滑 tween。**
- **结论收束感**：结束有明确收束（纪要落到桌上等）+ 结论**可复制/导出**。
- **猫**：挪角落；确认点猫不打断正在播放的发言。

# 作品集价值项（强烈建议，单独列）

> 观看者 30 秒内会想："这跟循环调 5 次 API、换 5 个 prompt 有啥区别？"

### 让"编排逻辑"被看见｜代码为主
- 加一个「**查看编排逻辑**」开关：展示 `主持人点名 → 专家响应 → 审稿人挑战 → 总结器汇总` 的流程/依赖，甚至每轮耗时、本次调用了哪些角色、各自贡献。
- **评审原话：这一个开关的加分大于所有动画之和。** 建议尽早排期。
